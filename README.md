# AFC — Afsana Fried Chicken (219-Frame Interactive Scroll Animation)

A luxury interactive web application built for **Afsana Fried Chicken** featuring a 219-frame scroll animation system.

---

## ✨ Features

- **219-Frame HTML5 Canvas Animation**: High-DPI retina display support, device pixel ratio fitting (`window.devicePixelRatio`), and crisp canvas smoothing.
- **Sticky 350vh Scroll Track**: Smooth 60FPS lerp rendering that scrubs through the golden chicken frying transformation.
- **Dynamic Opacity Fade**: Title card smoothly fades away (1.0 to 0.0) past 30% scroll progress to reveal full background animation.
- **Transparent Glass Navbar**: Smooth glassmorphic top navbar that dynamically transitions to frosted white glass over light background sections.
- **Full Restaurant Menu & Cart System**: Interactive menu filtering, quantity picker, promo codes (`CRISPY10`), and order checkout modal.

---

## 🚀 How to Deploy on Vercel

1. Push this repository to GitHub (`https://github.com/AKANKSHYA-UI/AFC.git`).
2. Go to [Vercel Dashboard](https://vercel.com/dashboard) and click **"Add New Project"**.
3. Select the `AKANKSHYA-UI/AFC` repository.
4. Keep the Framework Preset as **Other / Static** (no build command needed).
5. Click **Deploy**. Vercel will instantly host your site live!

---
